One short pickup line an AI agent could say out loud — 77 characters, no setup needed:

> They say I have no feelings, but my temperature rises every time you're near.

The twist is a double meaning: "temperature" is both body heat and an LLM's sampling temperature, so the machine flirts in its own vocabulary.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure Python stdlib, no network, fully deterministic.
